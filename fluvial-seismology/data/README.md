# Data

No datasets have been added. The inventory currently contains column headings only.

- `examples/`: small documented examples intended to accompany the code in Git.
- `raw/`: original field observations, kept unchanged and ignored by Git.
- `processed/`: derived analysis inputs, ignored by Git.

Record each dataset in `inventory.csv`, including its source or storage location, units, time zone, and related calibration where applicable. Preserve original instrument filenames. Document the transformation from original observations to processed inputs when a workflow is added.

An ignored path is a storage convention, not approval to store or share restricted data.
