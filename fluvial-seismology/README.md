# Fluvial seismology

Directory scaffold for seismic processing and river-flow/sediment modelling. No notebooks, scripts, recordings, or model runs have been added.

| Directory | Intended contents |
| --- | --- |
| `notebooks/preparation/` | Acquisition and waveform preparation. |
| `notebooks/instrument-calibration/` | Instrument calibration and diagnostic workflows. |
| `notebooks/spectral-analysis/` | Screening, spectra, and spectrogram analysis. |
| `notebooks/modelling/` | Turbulence, bedload, and inversion workflows. |
| `notebooks/exploratory/` | Notebook experiments and alternative approaches. |
| `scripts/processing/` | Reusable acquisition, signal-processing, calibration, and plotting functions. |
| `scripts/models/` | Scientific model and inversion routines. |
| `config/` | Station/input selection, model settings, and environment definitions when added. |
| [data/](data/README.md) | Examples, recordings, derived inputs, and an inventory. |
| [results/](results/README.md) | Figures, tables, and records grouped by analysis run. |

See [research methods](../docs/research-methods.md) and [source provenance](../docs/provenance.md).
