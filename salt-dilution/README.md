# Salt-dilution discharge analysis

Directory scaffold for conductivity-based discharge analysis. No notebooks, scripts, or datasets have been added.

| Directory | Intended contents |
| --- | --- |
| `notebooks/` | Main discharge-analysis notebooks. |
| `notebooks/exploratory/` | Investigations, trials, and unfinished notebook work. |
| `scripts/processing/` | Calibration, conductivity processing, discharge calculations, and supporting functions. |
| `scripts/parsers/` | Instrument-export readers and format conversion. |
| `scripts/experimental/` | Unfinished alternative implementations, with their status documented. |
| `config/` | Input selection, measurement windows, and analysis parameters. |
| [data/](data/README.md) | Examples, original measurements, derived inputs, and an inventory. |
| [results/](results/README.md) | Figures, tables, and records grouped by analysis run. |

See [research methods](../docs/research-methods.md) and [source provenance](../docs/provenance.md).
